# Changelog

All notable changes to this project will be documented here.

## 0.1.0 - Unreleased

- Add core entropy signals for actions, tools, trajectories, uncertainty reduction, temporal curves, and outcome stability.
- Add `AgentRun`, `AgentEvent`, and `InformationState` as the framework-neutral trace contract.
- Add `EntropyObserver` and `ObservabilityReport` for trace-derived observability telemetry.
- Add generic, LangChain, and Google ADK-style adapters.
- Add JSON/JSONL loading and the `eea` CLI.
- Add a minimal workload harness with sample QA and coding tasks.
- Add optional matplotlib entropy curve plotting.
